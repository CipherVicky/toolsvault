Setup Guide
Install in 5 Minutes
Follow these steps to get the extension running in your browser.
1
Download the Extension
Click the download button to get the ZIP file

Click the Download Extension button at the top of this page. Your browser will download a ZIP file to your Downloads folder. No need to extract it — you'll install the ZIP directly.

Make sure you click the download button on this page — do not download from any other source.
2
Open Chrome Extensions
Navigate to chrome://extensions in your browser

Type chrome://extensions in the address bar and press Enter. This opens the Extensions management page.

On Edge use edge://extensions. On Brave use brave://extensions.
3
Enable Developer Mode
Toggle Developer mode in the top-right corner

On the Extensions page, find the Developer mode toggle in the top-right corner and switch it ON.

This is required for private extensions not on the Chrome Web Store. It is completely safe and standard practice.
4
Drag & Drop the ZIP to Install
Drag the downloaded ZIP onto the page — Drop to install

Open your Downloads folder, then drag the ZIP file straight onto the chrome://extensions page. When you see “Drop to install”, release it — Chrome installs it instantly. No extracting needed.

If your Chrome window is maximized, shrink it a little (or use two windows side by side) so you can see both your Downloads folder and the extensions page while you drag.
If a "Keep / Discard" prompt appears, click Keep — the file is safe and downloaded from this official page.
You're All Set!
Extension is installed and ready to use

The ToolsVault icon will now appear in your browser toolbar. Click it to see your active session status.

Pin the extension — click the puzzle piece icon in Chrome's toolbar and pin ToolsVault for quick access.
Got Questions?
Frequently Asked Questions
Why do I need to enable Developer Mode?
This extension is private and not listed on the Chrome Web Store. Developer Mode allows you to load it manually — this is a standard practice used by enterprises and private tools. It is completely safe as long as you download only from this official page.
Is my data safe with this extension?
Yes. Our Cookie Vault system means real session values never exist in your browser's cookie jar — only encrypted garbage. Even if someone exports your cookies, they get useless data. Credentials are never sent to any third party.
Will the extension auto-update?
Not automatically. When we release a new version, older versions stop working and you'll see an "Update Required" message when accessing a tool. To update: remove the old ToolsVault extension from chrome://extensions, download the latest ZIP from this page, and drag it onto chrome://extensions again — same one-step install, no extracting.
Which browsers are supported?
Chrome, Microsoft Edge, and Brave are fully supported. Any Chromium-based browser should work. Firefox is not currently supported as it uses a different extension API.
What if the extension stops working?
First check that Developer Mode is still enabled. Try removing the extension from chrome://extensions, then download a fresh ZIP from this page and drag it onto the extensions page again. If issues persist, restart Chrome and re-install.
